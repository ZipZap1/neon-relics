# Neon Relics

Premium-looking browser prototype for an idle/card hybrid game.

## Run locally

```bash
python3 -m http.server 8123 --directory games/neon-relics
```

Open: http://127.0.0.1:8123

## Current features

- Neon/glassmorphism UI
- Animated relic cards with rarity tiers
- Idle credit generation
- Pack opening / card reveal animation
- Card upgrades
- Global research upgrades
- Overdrive mode
- Canvas particle bursts
- Responsive layout for mobile/desktop
